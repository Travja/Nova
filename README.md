# Nova screenshots

Screenshots for Nova's docs and pull requests live on this branch, not on
`main`, so a clone of `main` does not carry megabytes of PNGs it never needs.

Link to them with their raw URL:

    https://raw.githubusercontent.com/Travja/Nova/screenshots/<path>

From `main`, publish a directory here with
`scripts/publish-screenshots.sh <dir> <issue>-<slug>`.
